# Dzherelo

**Збирач відкритих військових і технічних документів.** Приводить бібліотеку з відкритим доступом до одного дерева на диску й тримає правду про кожен документ в окремому каталозі.

Не пошукова система і не заміна бібліотеці: проходить перелік, забирає файл, перевіряє, що це справді файл, і записує, звідки він узятий.

## Що вміє

- **87 бібліотек** у реєстрі, **6 родин платформ**: OAI-PMH, DSpace, WordPress, sitemap, HTML, статичні каталоги
- **Каталог як джерело істини**: `id` = перші 16 символів sha256 **вмісту** (не змінюється при перейменуванні чи дзеркалі), версії запису, позначки видалення, компакція, ремонт рваного хвоста
- **Дерево**: `library/<бібліотека>/<тип>/<рік>/<назва>.pdf`, 7 типів, одна конвенція назв
- **Відмови не зникають**: 8 кодів причин, черга з двома спробами, повтор перед наступним прогоном
- **Редакції**: нова редакція документа позначає попередню як замінену, історія лишається
- **Теми й покриття**: рахується з каталогу, показує прогалини, а не вашу уяву про них
- **Сторінки без PDF** зберігаються як аркуші A4 у стилі канону (WebView2 `PrintToPdfAsync`, без Word і Python)
- **Секрети** — у DPAPI (Windows Credential Manager), не в конфігу й не в релізі

## Встановлення

Один файл. Запустити `Setup.exe` (або `Dzherelo.exe --setup`):

- перевіряє WebView2 Runtime, права запису, вільне місце
- докочує WebView2, якщо його немає
- ставить у `%LOCALAPPDATA%\Dzherelo\app\<версія>\`, пише запис у «Програми й засоби»
- створює ярлики в «Пуску» й на робочому столі

Видалення: `--uninstall` (лишає дані) або `--uninstall --purge` (без слідів). Тека бібліотеки не чіпається без явного `--remove-library`.

## Командний рядок

```
Dzherelo.exe                      вікно
Dzherelo.exe --setup              встановлення
Dzherelo.exe --collect --out <тека> [--sources all|id,id] [--max N] [--since РРРР] [--budget хв]
Dzherelo.exe --list               перелік бібліотек
Dzherelo.exe --topics [тека]      покриття тем
Dzherelo.exe --reindex <тека>     міграція дерево → каталог
Dzherelo.exe --relayout <тека>    вирівняти дерево за конвенцією
Dzherelo.exe --canon <файл.html> [--out файл.pdf]
Dzherelo.exe --selftest           самоперевірка
```

Коди виходу: `0` гаразд · `1` джерело впало · `2` нічого не вибрано · `3` тека зайнята · `130` зупинено людиною.

## Безпека й межі

- Пейвол не обходиться. Якщо сервер не віддає файл без картки доступу — застосунок шукає той самий документ в іншому відкритому джерелі й **позначає провенанс**.
- Мережа зникла — пауза, проба кожні 30 с, продовження з того самого місця.
- Один екземпляр, DPI PerMonitorV2, прогрес у таскбарі, drag&drop файлів.

## Збірка

```
dotnet build -c Release
powershell -ExecutionPolicy Bypass -File package.ps1     # release/Dzherelo.exe + Setup.exe + latest.txt
Dzherelo.exe --selftest                                   # мусить бути «УСІ ПЕРЕВІРКИ ПРОЙДЕНО»
```

Потрібен .NET 10 SDK. Реліз — self-contained, single-file, без супутніх dll.
