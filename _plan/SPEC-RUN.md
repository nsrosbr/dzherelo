# SPEC-RUN — великий прогін суджень і рев'ю (2026-11-09)

## Мета
1. Класифікувати всі документи бібліотеки `_live` (тип / тема / мова) моделлю OpenRouter.
2. Після цього — незалежне рев'ю коду Kimi K3.1 Pro, з збереженим результатом.

## Залізні правила (щоб обрив мережі не коштував грошей і роботи)
1. **Стан на диску після КОЖНОГО документа**: `_live/state/judge-state.jsonl`
   рядок = `{"sha": "...", "ok": true|false, "model": "...", "ts": "...", "attempts": N, "why": "..."}`.
2. **Ідемпотентність**: повторний запуск бере лише те, чого немає в стані з `ok=true`.
   Документ, що вже має тип і тему в каталозі, не викликається вдруге.
3. **Ретраї**: на кожен документ — до 3 спроб із паузою 2с, 10с, 30с. Після цього `ok=false` з причиною,
   і прогін іде далі (один поганий документ не зупиняє 3000).
4. **Мережевий обрив**: якщо 10 документів підряд впали з мережевою причиною — пауза 60с і повторна спроба;
   після 3 таких циклів — коректна зупинка з кодом 3 і збереженим станом (наступний запуск продовжить).
5. **Ніяких вигаданих результатів**: якщо модель не відповіла — документ лишається без змін, у стані `ok=false`.
6. **Гроші**: ліміт — стоп після `--limit` документів або при досягненні орієнтовного бюджету (рахунок за токенами).

## Порядок виконання
1. `--judge-all --model openai/gpt-4o-mini --limit 3144`
2. Перевірка: скільки `ok=true`, скільки `ok=false`, скільки документів досі без типу/теми.
3. Рев'ю Kimi: код + доки одним пакетом, результат у `_plan/review-kimi.md`, повторний запуск не потрібен,
   якщо файл уже є (щоб не платити двічі).
4. Виправлення за рев'ю — окремими комітами, з `--selftest` після кожного блоку.

## Критерії готовності
- `judge-state.jsonl`: `ok=true` на ≥ 95% документів;
- документів без типу/теми — менше 5%;
- рев'ю-файл існує й містить перелік знахідок із номерами рядків;
- `--selftest` зелений, реліз перепакований, push у `main`.

## Що НЕ робимо в цьому прогоні
- не змінюємо таксономію тем;
- не чіпаємо джерела, які вже працюють (ISW/RUSI/BNTU), крім виправлень за рев'ю;
- не запускаємо повний збір по всіх 87 джерелах (це окрема операція і окремі години).
