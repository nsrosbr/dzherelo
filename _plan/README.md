# План і недоглянуті прогони

- `queue.json` — черга робіт. Крон бере першу `todo`, робить, ставить `done` з доказом або `blocked` з причиною.
- `progress.md` — журнал, дописується.
- `run-unattended.ps1` — супервізор застосунку: перезапускає прогін після збою, спиняється на 0/2/130 або коли вільно < 2 ГБ.

Зупинити крон: `/cron` → pause, або сказати мені «зупини цикл».
