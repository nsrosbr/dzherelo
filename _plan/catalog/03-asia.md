# Азія: реальні бібліотеки/сховища військово-інженерних документів

Дата перевірки: 2026-11-13. Метод: прямий HTTP-запит (curl) + web_extract/browser для кожного хоста.
Позначки: **[пер.]** — перевірено особисто; **[част.]** — частково (хост живий, вміст не підтверджено); **[не перев.]** — не вдалося перевірити (хост недоступний з цієї мережі / WAF).

Ключовий висновок: у Східній Азії **немає жодного відкритого сховища бойових статутів/настанов** (їх усіх тримають у закритому контурі). Реально працює лише один великий відкритий масив саме інженерних текстів — **Тайвань, портал 軍事期刊 (陸軍工兵半年刊)**. Решта — або історичні фонди (JACAR, NDL, modernhistory), або платні агрегатори, або геоблоковані сайти.
