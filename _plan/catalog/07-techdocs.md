# Техдокументація на інженерну техніку — реальні джерела

Дата перевірки: 13.11.2026. Метод: `curl -I/GET` (HTTP-статус, `Content-Length`, `Content-Disposition`), `web_extract`, браузер (рендер сторінок djvu.online / DSpace), DSpace REST API.
Позначки: **[П]** — перевірено особисто (файл/сторінка відкривались, заголовок і розмір збігаються); **[Ч]** — перевірено частково (є в індексі/каталозі, але файл не відкривався, або сайт блокує ботів); **[?]** — не перевірено, потребує ручної перевірки.

Ключове обмеження: більшість ТОіЕ на ІМР-2, БАТ-2, ПЗМ-2, МТУ, ПМП — радянські видання з грифом «Для службового користування». У вільному доступі лежать або скани-«витоки», або легальні пізніші навчальні видання (БНТУ, університети ДСНС, ЗСУ). Нижче це розділено явно.

## V. Прогалини та ризики
- **МТУ-72, ПП-91, M3, GQL-111** — у відкритому доступі лише описи/ТТХ, без керівництв. Закриваються або закупівлею паперу (dzmd.ru, «Военная книга»), або зверненням до кафедр (НАСВ, ВІКНУ) — там навчальні фонди, не публічні.
- **«Битий» SSL** на military-references.com і **анти-бот** на army.mod.uk, rafael.co.il: посилання робочі, але автоматичні перевірки падають — не вважати це «мертвим» джерелом.
- **Гриф ДСП**: каталог СИВ РФ і більшість ТОіЕ формально не призначені для публічного поширення; для довідкової бази полку це ок, для публікації — ні.
- **Не перевірено зовсім:** вміст dsns.gov.ua PDF, сторінка ODIN (JS), брошура Rafael (анти-бот), силабуси НАСВ. Позначені [?]/[Ч] — не цитувати як «підтверджено».
